## Historial anterior

El commit inicial incluye PDF, caches y credenciales academicas de demostracion. Limpiar el estado actual no elimina esas versiones. Si alguna credencial antigua se ha usado fuera de las practicas, revocala; una reescritura no invalida credenciales ni elimina copias existentes.

Ambas alternativas cambian los identificadores de commit y pueden exigir una actualizacion forzada del remoto. El historial no se ha reescrito automaticamente: conserva primero una copia privada y decide que historia deseas mantener. Un repositorio nuevo con solo el estado actual evita distribuir los PDF desde el primer commit.

## CV

**IoT Cloud Platform | Proyecto academico de sistemas distribuidos**

- Desarrollo de un prototipo incremental de monitorizacion de contenedores con Python, MQTT/Mosquitto y APIs REST Flask.
- Separacion de dispositivos y telemetria en microservicios con bases MariaDB independientes; despliegue mediante Docker Compose en Linux.
- Integracion de una interfaz web para posiciones, medidas y configuracion remota de dispositivos simulados.

En DevOps/Cloud, destaca contenerizacion, redes, configuracion por entorno y diagnostico de servicios. En Technical Sales, destaca la demostracion del flujo entre dispositivo, servicios y visualizacion. Incluye GCP como experiencia de despliegue solo si lo has ejecutado alli; el repositorio no provisiona infraestructura GCP.
